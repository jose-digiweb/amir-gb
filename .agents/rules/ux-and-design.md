# UX, design and copy

## Interface

- **Disabled controls explain themselves on demand.** Disable the control and give the reason when
  the user asks, through a small "Why?" on the control that opens a popover. Never park standing
  explanatory copy next to it, and show the blocked state only once the server confirms the reason.
- **One click, one action.** A control's look depends only on its own state, never on a sibling's.
  If a rule across items blocks a press, let the press happen and refuse it then, with the reason on
  demand.
- **Design around the message.** Start from what the surface has to say and the states it can be
  in, not from restyling it. Stand out through brand and meaning, never through size: stay inside
  the page's type scale, and never sell with a big number. Offer the restrained version first.
- **Light and dark belong to the viewer.** A theme is never a design variant, and every design has
  to work in both.
- **Mobile drops repeats.** On a phone, a section that says what the next one says gets cut, and any
  line only it had moves to the section that stays.

## Copy

- **No dashes as punctuation** in anything a person reads: UI text, buttons, errors, emails and PR
  descriptions, in every language. No em dashes, and no hyphens standing in for them. Use two
  sentences, a comma or a colon. Prefer a short message and a concrete action over an explanatory
  paragraph.
